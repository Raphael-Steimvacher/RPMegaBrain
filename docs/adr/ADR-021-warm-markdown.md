# ADR-021 — WARM canônica em Markdown

Status: aceita em 11/09/2026.

## Decisão

Cada memória WARM ativa é um Markdown legível com front matter estruturado, hash do conteúdo, aprovação humana e histórico de revisões. O arquivo canônico fica no estado privado do perfil, fora do Git.

## Consequências

O usuário consegue inspecionar e exportar memórias sem uma ferramenta proprietária. Escrita ativa exige aprovação do hash exato.
