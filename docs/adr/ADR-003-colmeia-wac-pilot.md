# ADR-003 — WAC como fluxo piloto

Status: adotado na alpha.1. Data: 2026-09-11.

## Contexto

O primeiro release precisa atravessar definição, investigação, planejamento e avaliação em uma tarefa observável.

## Decisão

Usar o workflow WAC; testar o ciclo primeiro com dados sintéticos. Não importar tickets ou dados da ColmeIA no núcleo.

## Consequências

A primeira WAC real depende de overlay autorizado e adapter. A avaliação da demo não é baseline da qualidade do modelo.
